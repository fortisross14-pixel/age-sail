# Art sources

Concept sheets generated with ChatGPT and approved as the game's style reference.
They are source sheets, not game-ready sprites: a script will cut them into
transparent, same-scale sprites under `public/sprites/`.

## Map style (`source/map/`)
Sepia ink line art with light watercolour on parchment.

| File | Contents |
| --- | --- |
| `style-board.png` | Overall look: chart, palette strip, lettering |
| `fog-states.png` | Unknown / charted / seen: the target for the map renderer |
| `colonies.png` | 6 colony types x 3 sizes (outpost, town, city) |
| `land-units.png` | Conquistador, musketeer, pikeman, cannon, cavalry, friar, colonist, scout (blank banners, tinted in code) |
| `terrain-symbols.png` | Mountains, hills, deciduous, conifers, palms, marsh, rocks |
| `ships.png` | Caravel, carrack, galleon, fluyt, sloop, frigate, ship of the line |
| `parchment-tile.png` | Tileable parchment texture |
| `ornaments.png` | Compass roses, cartouche, sea serpent, whale, wind head |
| `goods.png` | 16 trade goods icons |

## Panel art (`source/panels/`)
Painted miniatures, used large in drawers and cards (unit cards, colony screen),
never on the map.

## Rights
Generated with ChatGPT; under OpenAI's terms the outputs belong to the project.
Plan to have an illustrator redraw a cohesive set before v1.0.
